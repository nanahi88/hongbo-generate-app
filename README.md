# 홍보자동화

매장 사진과 가게 정보를 넣으면, 인스타그램용 사진과 채널별 홍보 문구를 한 번에 만들어 주는 파이썬 프로그램입니다. 개발을 모르는 자영업자가 혼자 쓸 수 있도록 만들었습니다.

## 주요 기능

**사진 변환**
- `자료` 폴더의 jpg, png 사진을 모두 변환합니다. (원본은 바꾸지 않고 읽기만 합니다.)
- 사진 가운데를 기준으로 1080 x 1080 정사각형으로 자릅니다. 사진이 찌그러지지 않습니다.
- 오른쪽 아래에 로고를 넣습니다. 로고 뒤에는 반투명 흰 바탕과 은은한 그림자가 들어갑니다.
- 로고 파일이 없으면 오류 없이 로고만 건너뜁니다.

**홍보 문구 만들기**
- `자료/가게 정보.txt`를 읽어 아래 문구를 만듭니다.
  - 인스타그램: 감성형 / 정보형 / 이벤트형 3종 + 해시태그 10개
  - 네이버 블로그: 제목 + 본문(약 900자) + 해시태그
  - 카카오톡 단골 공지: 3줄
- `자료/내 말투.txt`(직접 쓴 글)를 보고 이모지를 쓰는지 확인해 문구에 반영합니다. 문장은 인사 없이 짧게 끊는 "~습니다" 체로 만듭니다.
- 가게 정보에 없는 내용은 지어내지 않습니다.

**결과 저장**
- 실행할 때마다 `완성` 폴더 안에 `날짜_시분` 이름의 새 폴더(예: `2026-10-21_1516`)를 만들어 이번 결과만 담습니다. 이전 결과와 섞이거나 덮어쓰지 않습니다.

## 폴더 구성

| 경로 | 설명 |
| --- | --- |
| `사진변환.py` | 메인 프로그램 (사진 변환 + 문구 만들기) |
| `실행.bat` | 더블클릭으로 실행하는 파일 |
| `로고아이콘.ico` | 바탕화면 바로가기에 쓰는 아이콘 |
| `자료/` | 입력 폴더: 매장 사진, `로고.png`, `가게 정보.txt`, `내 말투.txt` |
| `완성/` | 결과 폴더: 실행할 때마다 새 폴더가 생김 |
| `사용설명서.txt` | 비개발자용 단계별 사용 설명서 |
| `CLAUDE.md` | 이 폴더에서 Claude와 작업할 때의 규칙 |

## 필요한 것

- Windows
- Python 3.12
- Pillow (`pip install Pillow`)

## 사용 방법

1. `자료` 폴더에 이번 주 사진을 넣습니다. (`로고.png`는 그대로 둡니다.)
2. `자료/가게 정보.txt`의 `이번 주 홍보할 것:` 아래 내용만 바꿉니다.
3. `실행.bat`을 더블클릭하거나, 터미널(PowerShell)에서 실행합니다.

   ```powershell
   python 사진변환.py --open
   ```

   `--open`을 붙이면 끝난 뒤 결과 폴더가 자동으로 열립니다.
4. `완성/날짜_시분/` 폴더에서 사진과 `홍보문구.txt`를 확인합니다.

자세한 설명은 [사용설명서.txt](사용설명서.txt)를 참고하세요.

## 가게 정보.txt 쓰는 법

```
가게 이름: 브릿지 커피
위치: 광주 북구 비엔날레 지구
가게 특징: 직접 로스팅하는 스페셜티 커피, 조용한 1인 좌석 많음
주 고객층: 30~40대 직장인, 근처 사무실 손님

이번 주 홍보할 것:
- 신메뉴 '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
- 오전 11시 이전 방문 시 아메리카노 500원 할인
```

- 각 줄은 `- `로 시작합니다.
- 신메뉴 이름은 작은따옴표 `' '` 안에, 가격은 숫자 뒤에 `원`을 붙입니다.
- 할인 줄에는 `할인`이라는 글자가 들어가야 합니다.
- 신메뉴 1개와 할인 1개만 문구에 반영됩니다.

## 참고

- 문구는 문장 틀에 가게 정보를 끼워 넣어 만듭니다. 올리기 전에 한 번 읽어 보고 다듬어 쓰세요.
- `완성/` 폴더에 쌓인 결과는 필요 없어지면 폴더째 지워도 됩니다.
